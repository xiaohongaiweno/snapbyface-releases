# SnapByFace

**Private Offline Face Search for Photos & Videos**

Find a person across your local photos and videos without uploading your media to a cloud photo service.

## What Is SnapByFace?

SnapByFace is a desktop application for searching people across local photo and video collections using face-based search. It supports Windows and macOS.

When a media library contains thousands of photos and videos, manually finding every file that contains a particular person can be time-consuming. SnapByFace provides a local face-search workflow that helps you add local media folders, build a local face index, select a target face, search your collection, and review matching results — all on your own computer.

## Features

- Search photos by face across large local collections
- Search videos by face and find person appearances in video footage
- Local face indexing for supported media formats
- Similarity-based search results
- Local-first media processing — your photos and videos stay on your computer
- Available for Windows and macOS

## How It Works

```text
Add local photos and videos
          ↓
Build a local face index
          ↓
Select a target face
          ↓
Search your media library
          ↓
Review matching results
```

1. **Add media folders** — Select folders containing your photos or videos.
2. **Analyze media** — SnapByFace scans the supported media files in your selected folders.
3. **Build the face index** — A local index of detected faces is created from your media.
4. **Select a target face** — Choose the person you want to find.
5. **Search** — SnapByFace searches your local media collection for matching faces.
6. **Review results** — Browse matching photos and video frames.

## Privacy First

SnapByFace is designed for local and private media search. Your photos and videos are processed on your own computer instead of being uploaded to a cloud photo service.

SnapByFace uses a local-first workflow for media processing and face search. The application itself may require an internet connection for functions such as license activation or update checks, but your media files are processed locally.
