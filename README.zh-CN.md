# SnapByFace

**私有、本地化的人脸搜索工具，支持照片和视频**

无需将照片和视频上传到云端相册服务，即可在本地媒体库中按人脸查找指定人物。

[官网](https://snapbyface.com/) · [下载](https://snapbyface.com/download/) · [文档](https://snapbyface.com/docs/)

---

## 什么是 SnapByFace？

SnapByFace 是一款支持 Windows 和 macOS 的桌面应用，帮助你在本地照片和视频库中通过人脸搜索快速查找指定人物。

当你的媒体库中包含成千上万张照片和视频时，手动逐一找出某个人的所有照片和视频非常耗时。SnapByFace 提供了一套本地化的人脸搜索流程：添加本地媒体文件夹、构建本地人脸索引、选择目标人脸、搜索媒体库、查看匹配结果——所有处理都在你自己的电脑上完成。

## 核心功能

- 在大量本地照片中按人脸搜索
- 在视频中按人脸搜索，查找特定人物的出现片段
- 支持多种媒体格式的本地人脸索引
- 基于相似度的搜索结果
- 本地优先处理——照片和视频保留在你的电脑上
- 支持 Windows 和 macOS

## 工作方式

```text
添加本地照片和视频
          ↓
构建本地人脸索引
          ↓
选择目标人脸
          ↓
搜索媒体库
          ↓
查看匹配结果
```

1. **添加媒体文件夹** — 选择包含照片或视频的文件夹。
2. **分析媒体** — SnapByFace 扫描所选文件夹中的媒体文件。
3. **构建人脸索引** — 基于检测到的面孔在本地创建索引。
4. **选择目标人脸** — 选择你要查找的人物。
5. **搜索** — SnapByFace 在本地媒体库中搜索匹配的人脸。
6. **查看结果** — 浏览匹配的照片和视频帧。

## 隐私与本地处理

SnapByFace 专为本地化、私密的人脸搜索而设计。你的照片和视频在你的电脑上完成处理，无需上传到云端相册服务。

SnapByFace 采用本地优先的工作流程进行媒体处理和人脸搜索。应用本身在许可激活或检查更新等功能上可能需要网络连接，但你的媒体文件始终在本地处理。
